# Shura frontend

The Vite frontend runs locally on `http://localhost:3006`.

## Run Locally

**Prerequisites:** Node.js and the Shura backend.

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and fill in the browser-safe Auth0 values. Never put client secrets or private API keys in this file.
3. Run the app:
   `npm run dev`

See [`../docs/LOCAL_E2E_SETUP.md`](../docs/LOCAL_E2E_SETUP.md) for the complete local environment and end-to-end QA procedure.
